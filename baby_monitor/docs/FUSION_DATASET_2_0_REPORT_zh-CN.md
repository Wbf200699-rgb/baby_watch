## 数据限制

- 所有样本仍是 `unreviewed/unassigned`，文件夹名称是本次标定采用的真实场景标签。
- 床温“空床”会话没有有效样本，因此不能从本包学习空床基线或医学温度阈值。
- 左侧站立加热会话多数帧没有形成可区分热源；融合层将其视为热成像无强证据，而不是错误判为无人。
- 数据只来自当前假人、配重、加热器和床面布置；换床垫、压力垫位置、摄像头角度或加热功率后必须重新标定。
