# 6 分钟项目演示顺序

演示使用假人和受控输入，提前确认网络、设备和传感器正常。AI 故事提前生成备用；避免等待现场生成占用演示时间。

| 时间 | 演示操作 | 让评委了解什么 |
| --- | --- | --- |
| 0:00–0:30 | 一句话介绍，再指认主控、网关与传感器 | 项目用于婴儿状态监护与异常提醒 |
| 0:30–1:10 | 打开 App 首页，展示宝宝状态、哭声、环境与风险等级 | 多路数据形成统一状态总览 |
| 1:10–1:55 | 手动打开视频与音频监听 | 手机通过服务端远程监护 |
| 1:55–2:55 | 展示五点床温、热成像与温度摘要、压力图和环境数据 | 系统既提供结论，也能展示判断依据 |
| 2:55–3:45 | 移动假人，观察位置、压力和在床状态变化 | 压力、视觉与热成像共同参与判断 |
| 3:45–4:45 | 用预先验证过的遮挡或床缘场景，展示告警、已查看与恢复 | 告警经过连续确认和生命周期处理 |
| 4:45–5:30 | 展示独立摇篮曲、AI 故事，操作暖光或拍抚 | 监护之外提供人工确认的安抚控制 |
| 5:30–6:00 | 展示资源曲线截图或网页，说明电脑本地 Plan B | 有性能观测与公网故障演示预案 |

结束语：系统完成了“多源采集—边缘判断—服务端转发—手机展示与提醒”的完整流程。

现场不必演示重新烧录切换 Plan B；用准备好的架构图和备用服务状态说明即可。告警触发时长以实际固件为准，提前安排输入；未触发时展示有效性诊断，备用录像须明确标注为录像。
