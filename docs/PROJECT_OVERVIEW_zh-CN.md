# 婴儿智能监护系统：项目详细说明

## 项目简介

面向婴幼儿看护场景，构建由 RA8P1 双核主控、ESP32-P4 网关、FastAPI 服务端及 Android App 组成的监护系统。通过视觉、声音、压力、热成像与环境数据共同描述宝宝状态，提供远程监护、分级提醒、事件追溯和人工安抚交互。

## 用户可感知的功能

看护者可以在手机中查看实时画面和声音、宝宝在床与活动状态、床面温度和环境情况。异常发生时查看风险等级与证据，并在处理后确认事件；平时可以播放摇篮曲或 AI 故事，手动控制暖光和拍抚装置。

## 工程难点与处理方式

| 问题 | 处理方式 |
| --- | --- |
| 单个传感器可能漏检或暂时失效 | 融合多路证据，单独保留来源有效性与诊断状态 |
| 音视频流量影响状态刷新 | 分离实时连接，使用有界队列与最新帧策略 |
| 服务器收到命令不代表设备已执行 | 使用硬件遥测回读确认开关状态 |
| 网络切换后旧响应污染当前界面 | 使用端点 generation 检查并重建连接与状态 |
| 公网不可用影响展示 | 提供电脑本地服务与人工双端点切换流程 |
| 系统运行问题缺少证据 | 记录事件、传感器有效性、CPU/NPU 利用率和内存余量 |

## 项目概况

**婴儿智能监护系统｜嵌入式与 Android 协同项目**

技术栈：Kotlin、Jetpack Compose、Coroutines、OkHttp、FastAPI、SQLite、FreeRTOS、RA8P1、ESP32-P4。

项目简介：基于多传感器与边缘计算实现婴儿状态监护，打通硬件采集、网关传输、服务端管理和 Android 远程交互，支持实时音视频、传感器可视化、分级告警与人工安抚。

## 核心模块职责

- Android 方向：基于 Jetpack Compose 与 StateFlow 实现监护、传感器和事件界面，接入 HTTP/SSE/WebSocket，处理弱网重连、最新帧背压、端点切换隔离与设备控制回读。
- 服务端方向：基于 FastAPI 与 SQLite 实现设备接入、遥测和事件管理、矩阵与媒体转发、采集会话及 AI 辅助服务。
- 嵌入式方向：基于 RA8P1 双核与 FreeRTOS 组织采集、共享内存、推理、融合和事件处理，通过 ESP32-P4 实现多条实时链路与控制转发。
- 工程验证方向：维护协议和业务测试、构建流水线及端到端演示用例，用实际测试结果说明可复现性。
